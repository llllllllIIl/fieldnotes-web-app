01 / The product

Auth-gated reading
No public access: every article route requires a signed-in session.
Admin console
Admins publish entries with cover images, tags and pinning from a dashboard.
Comments & reactions
Members discuss each entry; likes are open to all, fire is admin-only.
Hot-score ranking
Comments sort pinned-first, then reactions weighed against age (see notes).
Member profiles
Reputation stats — comments written, likes and fires received — plus recent activity.

02 / Case notes

The decisions that shaped the project, and what comes next.

JSON-only API

The FastAPI backend serves data and nothing else: no templates, no HTML. Auth is a dependency on every route — it verifies the Supabase JWT, resolves the profile and the admin flag, and rejects anything else. Keeping rendering out of the API made the frontend disposable: this static demo reuses the same styles with zero backend.

Passwords never touch the API

Supabase Auth owns credentials end to end (bcrypt). The backend only ever sees a verified user id and email, and the seed script creates the first admin through the Auth API — never by inserting into tables by hand.

Ranking as a pure function

Comment order is pinned → hot score → newest, computed by a pure function with unit tests. Likes come from any member; fires are admin-only endorsements worth five likes each; age decays the score so fresh replies can surface:

score = (likes + 5 × fires) / (age_hours + 2) ^ 1.2

The demo on this site re-implements the formula in the browser — toggle a few likes and watch the order change.

Vanilla frontend, deliberately

Reader, admin console and profile are plain HTML/CSS/JS: hash routing, template strings with an escapeHtml helper, no build step. It loads instantly and every bug is traceable in minutes. Past a dozen components I would reach for real state management — at this size, vanilla was the right call.

What I would do next

  • Cursor pagination on article and comment lists.
  • Rate-limit comment posting per member.
  • Row-level-security review so anon keys stay least-privilege.
